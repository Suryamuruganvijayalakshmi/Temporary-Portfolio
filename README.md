## 🌟 Overview

This portfolio is an artisanal digital experience built for **Surya V M** (Founder of [SignBridge](https://signbridge.click) & technology innovator based in Tamil Nadu, India). Merging tactile physical metaphors with cutting-edge web engineering, it presents an editorial journey across software systems, hardware telemetry, and venture architecture.

### ✨ Visual Philosophy & Design System
- **Tactile Warm Canvas**: Refined warm off-white canvas (`#fbfbf9`) with rich ink typography, crisp borders, and subtle analog film grain.
- **Micro-Animations & React Bits**: Interactive physics cards with `SpotlightCard`, dynamic laser `BorderBeam`, character decrypting `DecryptedText`, smooth `NumberTicker`, and velocity marquees.
- **GPU-Accelerated 3D WebGL Physics**: Interactive 3D hanging VIP ID badge with Verlet spring physics, realistic woven fabric ribbon lanyard, and 100vw drag mechanics.
- **Interactive Particle Globe**: Real-time particle projection rendering the authentic SignBridge brand identity on canvas.
- **Analog Vinyl Turntable**: High-fidelity vinyl playback with micro-groove platter, tone arm tracking, and ambient studio acoustics (*Sounddelicious // Portfolio Harmony*).
- **Physical Paper Folders (FolderFloat)**: Tactile floating paper archives with depth layers and interactive reading drawers.

## 💻 Local Development

### Prerequisites
- **Node.js**: v20.0.0 or higher
- **npm** or **pnpm**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Suryamuruganvijayalakshmi/Temporary-Portfolio.git
   cd Temporary-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and fill in your keys (optional for local frontend testing):
   ```bash
   cp .env.example .env
   ```

4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

5. **(Optional) Start the local backend mock API**:
   ```bash
   npm run server
   ```
   Runs the Express contact and health API on `http://localhost:5000` (automatically proxied by Vite).

6. **Build for production**:
   ```bash
   npm run build
   ```
   Compiles and minifies assets into `dist/`.

## 🌐 Deployment

### Cloudflare Pages / Workers (Recommended)
This repository is configured with `wrangler.toml` and `src/worker.js` for zero-configuration Cloudflare deployment:

```bash
# Build the production bundle
npm run build

# Deploy via Wrangler
npm run pages:deploy
# or
npm run deploy
```

## 🌟 Overview

This portfolio is an artisanal digital experience built for **Surya V M** (Founder of [SignBridge](https://signbridge.click) & technology innovator based in Tamil Nadu, India). Merging tactile physical metaphors with modern web performance, it redefines the portfolio standard through interactive hardware models, physical paper folders, analog vinyl playback, and procedural WebGL simulations.

### ✨ Visual Philosophy & Aesthetic
- **Cinematic Dark Theme**: Sleek, high-contrast dark palette (`#0a0c10` canvas, `#11141a` surface, `#161a22` elevated cards) with fine halftone grid textures and tactile film grain.
- **Sunlit Wall Shadows (Hero 28)**: High-resolution real-time ray-cast shadow simulation featuring ambient botanical leaf shadows dancing across a sunbeam where Surya's portrait is subtly revealed.
- **Tactile Physical Metaphors**: Physical stationery, postage stamps with serrated edges, metallic clips, paper file folders, archival tickets, and an interactive vinyl turntable.
- **Full Viewport 3D WebGL Physics**: Physics-driven 3D ID badge with spring tension, customizable elasticity, and edge-to-edge interactive dragging across the full screen width.

## 💻 Local Development

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **pnpm**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Suryamuruganvijayalakshmi/Surya-Portfolio.git
   cd Surya-Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and provide your credentials (optional for Supabase inquiries):
   ```bash
   cp .env.example .env
   ```

4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.

5. **Build for production**:
   ```bash
   npm run build
   ```
   Generates optimized, minified production assets in `dist/`.
